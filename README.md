## 🌟 Key Highlights

- ⚡ **100% In-Browser Execution:** Zero server-side storage, zero telemetry, zero analytics tracking.
- 📦 **Bulk Generation:** Generate 1 to 500 records in a single click with deterministic seeds for reproducible test runs.
- 🔄 **Dual Engine Architecture:**
  - **Live API Mode:** Fetches photographic profiles with realistic human avatars via RandomUser.
  - **Offline Pure-JS Engine:** Generates instant records client-side with complete hardware independence and no network latency.
- 📊 **24 Rich Data Fields:** Names, avatars, usernames, passwords, UUID v4, IPv4, MAC addresses, jobs, companies, street addresses, coordinates, and biometrics.
- 💳 **Luhn-Valid Test Cards:** Generates payment card numbers passing the ISO/IEC 7812 Mod-10 checksum algorithm (Visa, Mastercard, Amex, Discover).
- 🔢 **900-Series Safe SSNs:** Restricts test SSNs exclusively to the 900–999 area range (officially unissued by the Social Security Administration).
- 💾 **7 Production Export Formats:** JSON, JSON Schema (2020-12), CSV, Excel, MySQL, PostgreSQL, TSV, and XML.

## 💻 Code Integration Samples

### Python (`requests`)
```python
import requests

# Fetch 10 test users for API mocking
url = "https://randomuser.me/api/?results=10&nat=us,gb,ca"
response = requests.get(url)
users = response.json().get("results", [])

for u in users:
    print(f"{u['name']['first']} {u['name']['last']} <{u['email']}>")
```

### Node.js (`fetch`)
```javascript
async function getTestUsers(count = 5) {
  const res = await fetch(`https://randomuser.me/api/?results=${count}&inc=name,email,location,login`);
  const data = await res.json();
  return data.results.map(u => ({
    name: `${u.name.first} ${u.name.last}`,
    email: u.email,
    uuid: u.login.uuid,
    city: u.location.city
  }));
}

getTestUsers().then(console.log);
```

## 🔒 Privacy & Security by Design

1. **Zero Logging:** No user input, generated record, or exported batch is ever stored or transmitted to any remote backend server.
2. **Safe Test Data:** Card numbers satisfy Luhn checksum verification for front-end validation testing only and cannot be processed for real payments.
3. **No SSA Collisions:** SSN numbers are restricted to the 900 series to guarantee no accidental collision with real identity numbers.
